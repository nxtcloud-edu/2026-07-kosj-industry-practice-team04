# 시연 시나리오 — 「모아」

발표·영상 촬영용 진행 대본입니다. 화면 캡처는 [screenshots/](screenshots/)에 있습니다.

## 0. 준비 (2분)

```bash
# 터미널 1 — 백엔드
cd backend
cp .env.example .env      # 최초 1회 (관리자 토큰 demo-team04 포함)
npm start

# 터미널 2 — 프론트엔드
cd frontend
npm install               # 최초 1회
npm run dev
```

| 항목 | 값 |
|---|---|
| 시민 앱 | http://localhost:5173 |
| 관리자 콘솔 | http://localhost:5173/admin — 토큰 `demo-team04` |
| AI 분류 | `backend/.env`에 `MOA_GEMINI_API_KEY`가 있으면 실제 Gemini, 없으면 mock |
| 데이터 초기화 | `backend/data/`와 `backend/uploads/` 삭제 후 재시작 |

> 시연 전 체크: 백엔드 로그에 `분류 엔진: Gemini`가 찍히는지 확인. `mock`이면 키가 안 잡힌 것입니다.
> 준비물: **도로 파손 사진 1~2장**(휴대폰에 저장). 실제 사진일수록 AI 판정이 정확합니다.

## 2. 핵심 차별점 — 유사 신고 통합 (2분)

같은 자리에서 **한 번 더 신고**합니다.

1. `📷 사진으로 신고하기` → 다른 사진(또는 같은 도로의 다른 각도)
2. 위치를 **거의 같은 지점**으로 두고 `이 위치로 신고하기`
3. → **"주변에 비슷한 신고가 있나요?"** 후보 카드 표시 (거리 m 단위)
4. `기존 문제에 추가` 선택

> "반경 50m·같은 유형·72시간 안의 신고를 하나의 **대표 문제**로 모읍니다. 담당자 화면에서는 민원 2건이 아니라 **문제 1건, 신고 2건**으로 보입니다."

## 고령 사용자 관점 점검 결과 (#21)

시연 전 자동 점검으로 확보한 기준입니다. 재현: `frontend`가 떠 있는 상태에서 점검 스크립트 실행.

| 항목 | 기준 | 결과 |
|---|---|---|
| 터치 타깃 | 44×44 CSS px 이상 (WCAG 2.5.5) | 자체 UI 전부 충족 |
| 글자 크기 | 14px 이상 (고령 권장) | 자체 UI 전부 충족 |
| 명도 대비 | 4.5:1 이상 (WCAG AA) | 자체 UI 전부 충족 · 고대비 모드는 14:1 이상 |
| 확대 리플로 | 160%에서 가로 스크롤 없음 | 전 화면 충족 (375px 기준) |

**알려진 예외**: 지도의 `Leaflet | © OpenStreetMap` 저작권 표기(11px, 링크 45×12px). OpenStreetMap 라이선스상 표기 의무가 있고 지도 라이브러리가 렌더링하는 영역이라 그대로 둡니다. 신고 흐름에 필요한 조작이 아닙니다.

## 시연 중 사고 대비

| 증상 | 대처 |
|---|---|
| AI가 `mock`으로 뜬다 | `backend/.env`의 키 확인 후 백엔드 재시작. 시연은 그대로 진행 가능(유형만 부정확) |
| 지도가 안 뜬다 | 네트워크 확인(OSM 타일). 지도 없이도 좌표로 접수는 진행됨 |
| 위치 권한 거부됨 | 세종시청 좌표로 자동 폴백 — "권한을 막아도 동작합니다"로 넘어가면 됨 |
| 신고가 429로 거절 | IP당 시간당 5건 제한. 백엔드 재시작하면 초기화 |
| 관리자 토큰을 잊음 | 백엔드 시작 로그의 `관리자 토큰` 줄 확인 |
