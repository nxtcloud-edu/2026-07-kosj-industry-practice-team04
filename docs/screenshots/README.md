# 화면 캡처

실제로 동작하는 앱을 자동 조작해 찍은 화면입니다 (합성·목업 아님).
촬영 기준: 시민 화면 390×844 모바일, 관리자 1010px 데스크톱, AI 분류는 Gemini 실연동.

진행 순서와 대사는 [DEMO_SCENARIO.md](../DEMO_SCENARIO.md) 참고.
